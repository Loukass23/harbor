# Harbor for Tizen OS

This directory contains the configuration and build pipeline to port Harbor to Samsung Tizen TVs.

## Architecture

Harbor is a React SPA built with Vite. To run natively on Tizen OS, it is packaged as a **Tizen Web Application (.wgt)**.

- **`src/tizen/config.xml`**: The Tizen manifest file. Defines app privileges, network access, TV profile, and application entry point.
- **`src/tizen/dist/`**: Staged web build output generated by `pnpm run build:tizen`.
- **`src/tizen/dist/Debug/dist.wgt`**: Packaged and signed widget archive ready for installation on the TV.

## Build Pipeline

When building for Tizen (`pnpm run build:tizen`), `vite.config.ts` applies platform-specific adjustments:

1. **Relative Assets:** Sets `base: "./"` so static assets load correctly under the TV's local `file://` protocol.
2. **Output Routing:** Redirects output to `src/tizen/dist/`.
3. **Artifact Injection:** Uses a native Vite plugin hook (`writeBundle`) to copy `config.xml` and `icon.png` into the build output without requiring external shell utilities.
4. **Performance & TV Target:** Pre-configures target to `es2015` and optimizes code splitting chunks.

## CLI & Packaging

The pipeline uses the modern Tizen Core CLI (`tz`) provided by the Tizen VS Code extension.

### Commands

1. **Build the Web App**:

   ```bash
   pnpm run build:tizen
   ```

2. **Package & Sign the Widget**:

   ```bash
   pnpm run package:tizen
   ```

   _(Packages using the active security profile `SwormHarbor`)._

3. **Deploy & Install to Connected TV**:

   ```bash
   pnpm run install:tizen
   ```

4. **All-in-one Pipeline**:
   ```bash
   pnpm run tizen:deploy
   ```

## Troubleshooting & Requirements

- **Package ID Constraint**: Samsung TV firmware requires a 10-character alphanumeric package ID (e.g. `SwormHarb1`). Shorter IDs cause `Load archive info fail [118, -4]` during install.
- **Target Version**: Use `required_version="3.0"` or higher with `<tizen:profile name="tv" />` in `config.xml`.
- **Security Profile**: Ensure the TV's DUID is registered in your Samsung Distributor certificate and that you have clicked **"Permit to install applications"** on the target TV in the Tizen Device panel.
